## 🧪 Developer With a QA Mindset

One thing that differentiates me as a developer is my experience in **software testing and accessibility**.

I don't only ask:

> "Does the feature work?"

I also ask:

> "What happens when a real user interacts with it differently?"

That means considering:

- Keyboard-only users
- Screen-reader users
- Different screen sizes
- Invalid input
- Network failures
- API errors
- Authentication edge cases
- Browser differences
- Accessibility requirements
- Unexpected user behaviour

My goal is to build applications that are not only functional, but **reliable, accessible, and usable**.
